LONG (GitHub README / blog / Show HN)
--------------------------------------
YOU ASKED TO LEARN PYTHON.
One line in. A distributed system out.

SkillVector is an AI career-intelligence platform built on:

  · Llama 3.3 70B reasoning over real labor-market data
  · A 3-layer retrieval pipeline: L0 in-memory → L1 pgvector
    HNSW hybrid search (Mistral 1024-dim) → L2 Tavily live fetch
  · O*NET 29.0 — the U.S. Dept. of Labor's occupational database,
    1,000+ occupations, 19,000+ skill ratings
  · Advisory-lock concurrency, batched embeddings, 5-layer caching
  · An anti-cheat video player with heartbeat tracking and
    seek-skip detection — because yes, we built that too

Ask for a skill. Get a week-by-week roadmap, a skill-gap analysis,
and curated resources backed by live market data.

Built with FastAPI, Next.js 16, PostgreSQL + pgvector, and an
unhealthy amount of cache invalidation.

Try it. Break it. Then tell us what to build next.
