# Brag Plan: SkillVector

## What is this app?
SkillVector is an AI career-intelligence platform that turns a single line — "I want to learn Python" — into a week-by-week learning roadmap by running a full production RAG pipeline across O*NET labor data, live web search, 1024-dim vector embeddings, and multi-model LLM orchestration.

## The angle
**An over-engineered epic.** A career app that deploys advisory locks, a 5-layer cache, and an anti-cheat video player with seek-skip detection — to tell you what to study next week. The drama is real: the product's own landing page sells itself in massive cinematic display type ("AI-POWERED CAREER INTELLIGENCE") over an off-white canvas with indigo→sage gradients and floating stat chips. Play that visual language totally straight while the copy undercuts it with the absurd specificity of what actually happens under the hoodaine. The joke writes itself: the bigger and more trailer-like we make a *learning-path generator*, the funnier it is — but it lands as a real, earned flex because every beat is a genuine feature.

## Hook (first 2-3 seconds)
Full-bleed, cinematic: **"YOU ASKED TO LEARN PYTHON."** slams in over the off-white canvas in Syne 800, then a quiet sub-line: *"One line in. A distributed system out."* The gap between the humble request and the scale of what answers it is the entire joke, set up in one move.

## Key moments (the middle)
- **The pipeline fires.** Simulated app UI: cursor types "Python Developer" into the desired-role field, clicks **Generate Path**, and three layer-cards light up one by one — `L0 cache` → `L1 pgvector` → `L2 live web` — with an embedding-dimension counter ticking up to 1024.
- **The roadmap appears.** The generated week-by-week path reveals phase by phase (Python Foundations → OOP + Data Structures → Real-World Projects) with resource chips — "5 articles · 5 videos" — the product's signature output.
- **The anti-cheat player.** A video player UI with a pulsing heartbeat dot, "legitimate watch time 34%", then a seek jump → **⚠ SEEK-SKIP FLAGGED**. The absurd depth of the integrity system is the punchline no one expects from a studying app.

## Outro / punchline
Logo slams full-screen: **SKILLVECTOR** on the indigo→sage gradient, with the tagline **"AI-POWERED CAREER INTELLIGENCE"** beneath. Final beat, dry: *"From zero to job-ready. Please don't skip the video."* — a wink back at the anti-cheat feature from the very start.

## User flow worth showing
1. **Entry** — user sets desired role: types "Python Developer" in the field.
2. **Key action** — clicks Generate Path; the 3-layer RAG pipeline fires (L0 → L1 → L2, 1024-dim embeddings).
3. **Result** — a week-by-week phase roadmap appears with real resource counts, and the platform starts guarding the learning (anti-cheat player).
This is the centerpiece: the product doing its thing, not the landing page describing it.
